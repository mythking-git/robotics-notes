# Robotics Notes

Study guides for Robotics Engineering with AI (BEng), Year 1, WMG, University of Warwick.

Live site: https://notes.mythking.uk

- Editing and publishing: see [HOW-TO-EDIT.md](HOW-TO-EDIT.md).
- Guides live in `content/` (Markdown, Obsidian-style links and callouts, LaTeX maths).
- Diagrams are SVGs in `content/assets/`.
- Pushing to `main` builds the site with GitHub Actions and publishes it to the `site` branch. The server pulls that branch (see `deploy/docker-compose.yml`).

Built with [Quartz](https://quartz.jzhao.xyz) (MIT licence).
