## Maths
| Want | Formula | Guide |
|---|---|---|
| Product rule | $(uv)' = u'v + uv'$ | [[Calculus for kinematics]] |
| Chain rule | $\dfrac{dy}{dx} = \dfrac{dy}{du}\dfrac{du}{dx}$ | [[Calculus for kinematics]] |
| By parts | $\int u\,dv = uv - \int v\,du$ | [[Calculus for kinematics]] |
| Dot product | $\mathbf a\cdot\mathbf b = a_xb_x + a_yb_y + a_zb_z = \lvert\mathbf a\rvert\lvert\mathbf b\rvert\cos\theta$ | [[Vectors]] |
| Cross product | $\mathbf a\times\mathbf b$ = determinant with $\mathbf i, \mathbf j, \mathbf k$ on top | [[Vectors]] |
| Moment | $\mathbf M = \mathbf r\times\mathbf F$ | [[Vectors]] |
| Implicit | $\dfrac{d}{dt}f(x) = f'(x)\,\dot x$ | [[Implicit differentiation]] |

## Particle kinematics
| Want | Formula | Guide |
|---|---|---|
| Definitions | $v = \dot s$, $a = \dot v = \ddot s$, $a\,ds = v\,dv$ | [[Rectilinear motion]] |
| Constant $a$ | $v = v_0 + at$ · $s = s_0 + v_0t + \tfrac12at^2$ · $v^2 = v_0^2 + 2a(s - s_0)$ | [[Rectilinear motion]] |
| x–y components | $\mathbf v = \dot x\mathbf i + \dot y\mathbf j$, $\mathbf a = \ddot x\mathbf i + \ddot y\mathbf j$ | [[Curvilinear and circular motion]] |
| Circular motion | $v = r\omega$ · $a_t = r\alpha$ · $a_n = v^2/r = \omega^2r$ · $a = \sqrt{a_t^2 + a_n^2}$ | [[Curvilinear and circular motion]] |

## Rigid bodies and mechanisms
| Want | Formula | Guide |
|---|---|---|
| Angular definitions | $\omega = \dot\theta$, $\alpha = \dot\omega$, $\omega\,d\omega = \alpha\,d\theta$ | [[Rigid body rotation]] |
| Constant α | $\omega = \omega_0 + \alpha t$ · $\theta = \theta_0 + \omega_0t + \tfrac12\alpha t^2$ · $\omega^2 = \omega_0^2 + 2\alpha(\theta - \theta_0)$ | [[Rigid body rotation]] |
| Gears, belts (no slip) | $r_A\omega_A = r_B\omega_B$ · $r_A\alpha_A = r_B\alpha_B$ | [[Gear trains and belt drives]] |
| Relative velocity | $\mathbf v_B = \mathbf v_A + \boldsymbol\omega\times\mathbf r_{B/A}$ | [[Relative motion analysis]] |
| Relative acceleration | $\mathbf a_B = \mathbf a_A + \boldsymbol\alpha\times\mathbf r_{B/A} - \omega^2\mathbf r_{B/A}$ | [[Relative motion analysis]] |
| Cosine rule | $c^2 = a^2 + b^2 - 2ab\cos C$ | [[Absolute motion analysis]] |

## Conversions
- 1 rev = $2\pi$ rad · rpm × $2\pi/60$ = rad/s
- Angles in **radians** for $s = r\theta$ and $v = r\omega$
