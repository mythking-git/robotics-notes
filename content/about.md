## Who I am
I'm Mikey, a first-year student on Warwick's **Robotics Engineering with AI** BEng at WMG. I write these guides to understand the material properly, and in the hope they help someone else on the course, or anyone learning the same topics.

## How the guides are made
1. I take notes in lectures and seminars, in a private Obsidian vault.
2. For each topic, I rewrite the material as a stand-alone guide: the idea, a diagram, derivations, a worked example with **new numbers**, common mistakes and self-test questions.
3. Calculations are checked by working them through (and often in code), and the guide is checked against the course material before it's published.

## The AI note
**AI was used to help draft and structure these guides, generate the diagrams, and check calculations.** I direct and check the content, and I take responsibility for it, but mistakes are possible. If you're on the course, your lecturer and the official materials are the authority.

## Sources
- My own lecture and seminar notes.
- Standard textbooks for each topic, e.g. Bird, *Electrical Circuit Theory and Technology*; Hibbeler, *Engineering Mechanics*; Engineering Council and HSE guidance for the professional topics.
- Manufacturer datasheets, quoted as facts with the part named so you can check them.
- **Not included:** lecture slides, Moodle files, quiz or assessment answers, or anything I've submitted for marks.

## Found a mistake?
Open an issue on [GitHub](https://github.com/mythking-git/robotics-notes/issues) with the page name and what's wrong. Corrections are always welcome.

## How this site is built
| Layer | What | Why |
|---|---|---|
| **Writing** | [Obsidian](https://obsidian.md), Markdown files with wikilinks, callouts and LaTeX maths | Same tool I use for my own notes |
| **Diagrams** | Hand-coded SVGs generated by a small Python script | Sharp at any size, and easy to change |
| **Site generator** | [Quartz](https://quartz.jzhao.xyz) v5 (TypeScript, Node.js) | Built for Obsidian-style notes: backlinks, graph view, search, popover previews |
| **Maths** | KaTeX | Fast LaTeX rendering in the browser |
| **Source control** | Git and [GitHub](https://github.com/mythking-git/robotics-notes), pushed from Obsidian with the Obsidian Git plugin | Every change is versioned |
| **Build** | GitHub Actions | Builds the site on every push and publishes the finished files to a `site` branch |
| **Hosting** | My home server: Proxmox VE → a Debian LXC running Docker, managed with Dockge | Self-hosted, no third-party host |
| **Serving** | Two containers: one pulls the `site` branch every 5 minutes (alpine/git), one serves it (Caddy) | Updates go live automatically |
| **Network** | Nginx Proxy Manager (reverse proxy, Let's Encrypt HTTPS) and Cloudflare DNS | One public address for everything on the server |

```

                                                  │  pulled every 5 min
                     Cloudflare ▶ Nginx Proxy Manager ▶ Caddy (Docker, Proxmox LXC)
```
